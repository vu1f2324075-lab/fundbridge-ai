Design a professional, production-quality web application prototype called:

FUNDBRIDGE AI

Tagline:
Find the Right Funding. Know Why.

Product description:
FundBridge AI is an explainable AI-based funding decision-support platform for startups and MSMEs. It helps businesses analyse their funding readiness, discover relevant investors and government funding schemes, understand why an opportunity is recommended, and improve their funding proposal.

IMPORTANT:
Create ONLY the frontend UI/UX prototype.
Do not design or imply a working backend, real AI model, real API, payment system, or database.

The prototype must demonstrate the complete user workflow using realistic sample/mock data.

==================================================
DESIGN STYLE
==================================================

Create a premium, professional FINTECH / BUSINESS INTELLIGENCE interface.

The design should look like a real software product, not a college project and not an AI-generated template.

Visual characteristics:

- Clean white and very light grey backgrounds
- Deep navy as the main brand color
- Professional blue accent
- Dark charcoal text
- Green for positive/eligible/good status
- Amber for warnings/attention
- Red only for problems
- Thin subtle borders
- Very light shadows
- 8–12px corner radius
- Generous whitespace
- Strong alignment and grid system
- Consistent spacing
- Professional typography

Use Inter or a similar modern professional sans-serif font.

Avoid:

- Neon colors
- Cyberpunk design
- Futuristic AI graphics
- Robot illustrations
- Giant AI brain graphics
- Excessive gradients
- Glassmorphism
- Excessive rounded cards
- Excessive animations
- ChatGPT-like interface
- Generic SaaS template appearance

The visual language should communicate:

TRUST
CLARITY
DATA
PROFESSIONALISM
EXPLAINABILITY
